# Бипланы / Biplanes

Браузерная 2D-аркада для Яндекс Игр: воздушные дуэли 1×1 и непрерывная кампания из 50 уровней. Текущая сборка **v0.6.0** от 2 октября 2026 года использует TypeScript, Phaser и отдельный авторитетный сервер Node.js.

Рабочий прототип содержит оба режима, серверную экономику, ангар, задачи и новые мультяшные самолёты. Проект в Консоли Яндекс Игр ещё не создан; реальные покупки и публикация не подключены.

## Быстрый запуск

Проверено на Node.js 22 и npm 10. Установите зависимости из lockfile:

```powershell
npm ci
```

Откройте два терминала в корне проекта:

1. `npm run server` — сервер матчей и профилей на `http://127.0.0.1:5187`.
2. `npm run dev` — игра на `http://127.0.0.1:5186/`; Vite проксирует `/socket` на сервер.

`npm run build` проверяет TypeScript и собирает клиент в `dist/`. `npm run preview` открывает собранный клиент на `http://127.0.0.1:4186/`; игровой сервер должен оставаться запущенным. `npm test` выполняет 34 проверки правил, сохранений, платежного адаптера, интерполяции и реального WebSocket-сервера. Интеграционный тест использует порт 5197 и отдельное временное хранилище.

Локально Яндекс SDK не требуется. Все режимы требуют связи с сервером проекта; бесплатная офлайн-тренировка ещё не реализована. Гостевые профили сохраняются в `data/profiles.json`; этот каталог не входит в Git.

## Текущая реализация v0.6

Реализовано:

- Полёт, повороты, стрельба, попадания, столкновения, форсаж, перегрев, возрождение со щитом в дуэлях. Клавиатура: A/D или стрелки, пробел, Shift, Esc. На телефоне — кнопки с поддержкой нескольких касаний; бой в альбомной ориентации.
- Настоящий общий матч 1×1 через WebSocket. Очередь ищет человека, после 15 секунд допускает бота только при включённом разрешении. Выбор сохраняется; отмена и позднее включение ботов обработаны. Первичный подбор учитывает ранг и мощность самолёта; отдельный рейтинг мастерства ещё не реализован.
- Непрерывная зона из 50 записей уровней: полёт вправо, скалы, истребители, ПВО с предупреждением, тяжёлые самолёты. ПВО появляется с уровня 3, тяжёлые враги — с уровня 6; далее растут прочность, урон, частота появления и скорость карты. Сегменты пока процедурные, разнообразие предстоит расширить.
- Боссы 10/25/50 останавливают карту, используют правила дуэли и отдельную прочность. После 10/25 полёт продолжается; после 50 зона заканчивается. Полёт сохраняется при выходе; после смерти повторяется текущий уровень или босс.
- Серебро и опыт выдаёт сервер за уничтожения, уровни и активные дуэли. Золото за игру не выдаётся. Бездействие в дуэли не награждается; выход соперника не лишает активного игрока награды.
- Ангар, выбор самолёта, покупка Стрижа и Бастиона за серебро с ограничением по рангу, три ветки улучшений по пять уровней. Скат приобретается за 300 золота: при пикировании он быстрее охлаждает оружие. Без подключения платежей баланс золота остаётся нулевым.
- Три дневные и три недельные задачи, общий недельный бонус, семидневный цикл входа без сброса при пропуске. Выполненные незабранные награды сохраняются семь дней после конца периода; старые награды видны в архиве задач. Повторные запросы получения не дублируют награду, включая недельный бонус из архива.
- Семь оригинальных SVG: четыре самолёта игрока, вражеский перехватчик, тяжёлая машина и босс. Параллакс, винт поршневой машины, выхлоп реактивных двигателей, дым повреждений, трассеры, вспышки, попадания, взрывы с дымом и искрами, щиты, объявления уровней и боссов, всплывающие награды. Короткие звуки синтезируются через Web Audio, есть выключение звука.
- Два уникальных модуля по 120 золота: карбюратор увеличивает длительность форсажа с более медленным восстановлением, радиатор улучшает охлаждение ценой урона. Один активный модуль для всех самолётов; включение/снятие в ангаре.
- Обмен пакетов 10/50/100 золота на серебро или опыт с подтверждением. Повтор операции с тем же идентификатором не списывает золото снова. Баланс и запись о списании сохраняются до подтверждения клиенту; сбой диска откатывает операцию.
- События загрузки/геймплея/паузы, вход через Яндекс и облачная привязка ангара. Подготовлен платёжный адаптер: каталог SDK, подписанный список покупок, серверная HMAC-проверка, журнал чеков и восстановление незавершённых начислений. Расходуемый чек подтверждается SDK только после сохранения золота и журнала на сервере. Локально SDK не требуется. Реальные платежи в Яндексе ещё не проверены.

Структура: `shared/` — правила и данные; `server/` — очередь, симуляция, кошелёк и сохранение; `src/` — Phaser-сцена, интерфейс, звук и платформа; `public/art/` — исходные SVG; `tests/` — проверки правил и реального сервера.

Для проверки онлайна используйте два браузера или разные профили. Две вкладки одного аккаунта не создают двух соперников: новая вкладка заменяет старую сессию.

Локально профиль привязан к случайному гостевому токену в localStorage. После входа в Яндекс этот токен сохраняется через облачные данные игрока, чтобы открыть тот же ангар на другом устройстве. Покупки допускаются после успешной облачной привязки. Это гостевой серверный токен, а не проверенная сервером идентичность Яндекса: проверку подписанного Player нужно завершить до публичного запуска.

Сервер сохраняет аккаунты и контрольные точки атомарной заменой `data/profiles.json`, обычно раз в 500 мс; при аварийном завершении возможен небольшой откат обычного прогресса. Платёжные начисления, покупка самолётов/модулей и обмен ждут записи на диск. Файл и токены не входят в сборку и исключены из Git. Это однопроцессное хранилище для прототипа; нельзя запускать несколько экземпляров с одним файлом. Для публикации нужны резервное копирование и перенос в транзакционную БД.

Проверка v0.2: 29 автоматических проверок. Покрыты переходы всех трёх боссов, награды, перегрев, пауза и сохранения; архив наград на семь дней и недельный бонус после смены периода; общий онлайн-матч двух клиентов, очередь 15 секунд и отмена; подписи, повторный чек и попытка перенести чек в другой аккаунт; запись кошелька до подтверждения, повтор обмена и откат при сбое диска; восстановление/подтверждение покупок и отказ облачного сохранения в макете SDK. ## Обновление игры v0.5: настройки и читаемость

- Режим прохождения называется «Кампания». Под двумя кнопками запуска расположена широкая жёлтая кнопка «Как летать». В справке есть явная кнопка «Назад», которая остаётся доступной при прокрутке.
- В нижней навигации появилась вкладка «Настройки». Эффекты и музыка переключаются независимо, показывают текущее состояние и сохраняются на устройстве. Переключатели убраны из шапки и боевого HUD.
- Все подписи, вспомогательный текст, кнопки, уведомления и боевой интерфейс используют шрифт от 16 CSS px. Размер всплывающих наград и сообщений Phaser учитывает фактический масштаб canvas: награды от 16 px, заголовки уровней от 24 px, включая после изменения окна.
- Карточки задач стали крупнее и контрастнее: отдельные области цели и награды, заметный прогресс, состояния «В процессе», «Забрать» и «Получено». Ежедневный вход выделен золотой карточкой. Архив наград использует тот же формат.
- На телефоне выбран landscape для всей игры, включая меню. В вертикальном положении — полноэкранное «Поверните устройство», меню и управление недоступны, звук приостановлен. Кампания и дуэль с ботом ставятся на паузу и автоматически продолжаются после поворота; ручная пауза сохраняется. Поиск соперника отменяется при повороте в портрет. Уже начатая онлайн-дуэль продолжается, экран явно предупреждает об этом.
- При малой высоте главный экран становится компактнее, настройки звука стоят в двух колонках. Минимум 16 px сохраняется. Вертикальные сетки оставлены как резерв для узкого окна компьютера, а не как мобильный режим.

Проверка v0.5: TypeScript и production build; 34 автоматических проверки. В браузере проверены все вкладки на 320×640 и 390×844: нет текста менее 16 px и горизонтальной прокрутки. Режимы и «Как летать» видны без прокрутки. После выбора landscape также проверены 568×320 и 844×390, полный экран блокировки 390×844, автоматическая пауза/возобновление кампании и сохранение ручной паузы после поворота. Проверены отдельные аудиопереключатели и сохранение после перезагрузки, возврат из справки, запуск кампании, боевой HUD, пауза и поиск/отмена дуэли на 844×390. Это эмуляция размеров окна; замеры FPS на реальных телефонах не проводились.

## Обновление игры v0.4: интерфейс

- Стартовый экран открывается на вкладке «Играть»: небольшой выбранный самолёт и две большие кнопки в ряд — «Небесный рубеж» и «Один на один». Бирюзовый и янтарный акценты различают режимы, отдельная полоса «Играть»/«Продолжить» подчёркивает действие. Обе кнопки видны без прокрутки. Убраны приветственные тексты, характеристики, ранг, кошелёк и статус «Исправен» с главного экрана.
- Нижняя навигация: «Играть», «Самолёты», «Задачи», «Магазин». Краткая справка, звук и музыка доступны в небольших кнопках сверху. На главном экране нет дополнительных информационных панелей или бокового меню.
- «Самолёты» — полноценный ангар: коллекция, просмотр покупки, выбор принадлежащей машины, актуальные характеристики, три ветки улучшений и оснащение за золото. Выбор принадлежащей машины делает её активной; просмотр ещё не купленной не меняет самолёт для вылета. Цена, требуемый ранг и нехватка ресурсов видны рядом с действием. Существующие модули по-прежнему общие для всех самолётов, с одним активным модулем.
- Магазин содержит только пакеты золота и переплавку в серебро/опыт. Платные самолёты и модули перенесены в ангар. Реальные покупки по-прежнему недоступны до подключения проекта Яндекс Игр.
- Упрощены задачи, справка, ожидание соперника, пауза и возврат на главный экран. Отрисовка и правила боя сохранены. Код меню выделен в `src/menu.ts`.

Референс организации ангара: [официальный гайд World of Warplanes](https://worldofwarplanes.com/tutorials/guide/fundamentals) — характеристики и оснащение рядом с выбранным самолётом. Компоновка главного экрана и две явные кнопки определены требованиями пользователя.

Проверка v0.4: TypeScript и production build проходят. В браузере проверены старт и ангар на 320×640, старт, ангар, улучшения, магазин и задачи на 390×844, компоновка на 1280×720 и старт/бой на 844×390. Обе кнопки запуска видны без прокрутки, горизонтального переполнения нет. Проверены просмотр платного самолёта без изменения активной машины, переход к золоту, ограничения ранга/валюты, запуск сохранённого PvE, пауза/возврат, отмена поиска и автоматический запуск дуэли с ботом. Получение награды обновляет кошелёк и отметку задачи; серверное обновление сохраняет прокрутку текущей страницы в пределах её высоты.

- Все пиктограммы интерфейса — оригинальные SVG из `src/icons.ts`, без эмодзи и символьных замен. Четыре самолёта и вражеская модель заново нарисованы: разные формы, кабины и пилоты, стойки и расчалки, рёбра крыльев, заклёпки, материалы, свет и тени. Самолёты увеличены в бою; фон сохранён.
- Вместо покадровых скачков серверных снимков используется общий буфер движения самолётов, препятствий, снарядов и прокрутки карты. Обычный переход уровня сохраняет позицию и направление самолёта; переход в арену босса остаётся отдельной фазой.
- Добавлена оригинальная музыкальная петля `public/audio/sky-patrol.mp3` длительностью около 37 секунд. Музыка и звуки выключаются отдельно, настройки сохраняются. Музыка запускается после первого действия, становится тише в бою и останавливается при паузе, уходе вкладки в фон и рекламной паузе.

В браузере проверены меню на 1280×720 и 390×844 без горизонтальной прокрутки, поле 800×450 на десктопе и 636×358 на альбомном экране 844×390, сенсорные кнопки, загрузка моделей и музыкального файла, включение/выключение музыки в бою, остановка на паузе и возврат в ангар. ## Подключение будущего проекта Яндекс Игр

Проект в консоли пока не создан. Локальный магазин показывает «Покупки не подключены»; настоящие платежи не имитируются.

1. Создать проект и выбрать мобильную ориентацию **landscape** в Консоли Яндекс Игр ([требование платформы](https://yandex.ru/dev/games/doc/ru/requirements/1/10)). Затем загрузить содержимое `dist/` после `npm run build`. Разместить отдельный игровой сервер с HTTPS/WSS; указать его публичный адрес в `VITE_SERVER_URL` при сборке клиента.
2. Подключить покупки в консоли и создать расходуемые товары с точными ID `gold100`, `gold300`, `gold800`. Количество золота задаёт сервер; реальные цены берутся из каталога Яндекса. Цены и отображение валюты проверить в тестовом окружении.
3. Добавить секрет покупок этого проекта в переменную окружения **сервера** `YANDEX_PAYMENT_SECRET`. Не помещать секрет в исходники/клиент и не использовать префикс `VITE_`. Запуск `npm run server` читает окружение процесса; `.env.example` служит образцом и автоматически сервером не загружается.
4. В тестовом окружении Яндекса проверить вход/облако на двух устройствах, точный формат подписанного `getPurchases`, покупку каждого товара, отмену, потерю связи после оплаты, перезапуск сервера, восстановление и отсутствие двойной выдачи. Адаптер принимает только подписанный список завершённых покупок; ответ самого `purchase()` не используется для начисления.
5. Перед публикацией завершить проверку подписанного Player, производственное хранилище, обработку нагрузки и требования платформы. Подключённый секрет сам по себе не означает готовности принимать реальные платежи.

Основа интеграции: [покупки Яндекс SDK](https://yandex.ru/dev/games/doc/ru/sdk/sdk-purchases), [игрок и облачные данные](https://yandex.ru/dev/games/doc/ru/sdk/sdk-player). Подтверждение consumable после сохранения и проверка необработанных покупок при старте заложены в адаптер.

Следующий этап разработки: rewarded/interstitial-реклама, аналитика, обучение, разные тактики боссов и сегменты уровней, настройка баланса и эффектов. До публикации также нужны реальная проверка Яндекс SDK, серверная привязка личности, HTTPS/WSS и размещение, БД/резервные копии и нагрузочная проверка. Клиент требует отдельного сервера и пока не готов к публикации.
