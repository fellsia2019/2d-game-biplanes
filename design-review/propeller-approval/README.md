# Винтовой ангар: четыре модели и премиальный Феникс

Пользователь утвердил стиль всех четырёх исходных самолётов. Этот проход
разделяет конструкции обычных машин и предлагает пятую за золото.

- Сокол — стартовая машина; исходный синий самолёт сохранён.
- Стриж — первая покупка за серебро; компактный радиальный мотор, исходный бирюзовый самолёт сохранён.
- Янтарь — вторая покупка за серебро; более вытянутый силуэт и эллиптическое крыло (`assets/yantar-v2.png`).
- Рубин — третья покупка за серебро; два двигателя и два винта на крыле (`assets/rubin-v2.png`).
- Феникс — премиальная модель за золото: фиолетовый, бирюзовый, коралловый и золотой; эмблема и отключаемый искристый след (`assets/feniks.png`).

Назначения — концепция ангара. Цены, параметры и баланс пока не заданы.
Исходные PNG первого листа сохранены. Ранний двухбалочный набросок Рубина
сохранён как `rubin-v2-draft.png`, но не используется в превью.
Новые изображения созданы встроенным ImageGen. Полные промпты —
`generation.json` и `generation-v2.json`.

## Запуск

Из корня проекта:

```sh
npm run dev
```

Открыть http://127.0.0.1:5222/design-review/propeller-approval/

## Отрисовка

Canvas 2D использует буфер с учётом devicePixelRatio (до 3),
предварительно сглаженные уровни уменьшения текстур и high-quality smoothing.
Выбирается уровень чуть крупнее целевого размера в физических пикселях.
Это устраняет резкое уменьшение большого исходника на каждом кадре.
Обработка происходит только в памяти Canvas; PNG не изменяются.
Размер 120/180/320 задаётся в CSS-пикселях видимого самолёта.
Позиции и углы остаются непрерывными, без округления по кадрам.

Есть полёт пяти машин, выбор одной, A/D и стрелки, Shift, сенсорные кнопки,
пауза и вечерний фон. Золотой след Феникса теперь состоит из двух полос длиной не менее 80 CSS px
и 24 плавно движущихся искр. Видимость проверена при размере самолёта 120 px.
След можно отключить отдельно.

Для полёта используются отдельные `*-airframe.png` без нарисованных лопастей.
Их подготовил встроенный ImageGen точечной правкой утверждённых изображений;
промпты — в `generation-motion.json`. Исходный арт карточек сохранён.
Винты рисует `motion.js`: шесть отдельных вращающихся винтов на пяти моделях.
У Рубина два независимых винта на двигателях. Лопасти и корпуса используют
одни и те же поворот и отражение. Есть режим медленного вращения.
Пауза замораживает время винтов и следа вместе с полётом.
Отметки «Нравится» сохраняются локально и не отправляются в чат.

Это отдельное дизайнерское превью. Runtime игры, её модели и экономика не изменены.

## Проверка

Проверены загрузка и прозрачность всех пяти PNG, два реальных винта Рубина,
размеры 120/180/320, весь ангар и выбор одного самолёта, пауза,
вечерний фон, эффект Феникса. На экране 1046 CSS px Canvas использует
2092 физических px по ширине. Ошибок консоли не обнаружено.
Скрипт прошёл `node --check`. Проверка всех тестов игры не требуется,
поскольку изменение изолировано от runtime.

Дополнительная проверка эффектов: золотой след виден на дневном фоне при 120 px,
его переключатель убирает и полосы, и искры. Винты проверены крупно,
включая оба у Рубина. При паузе два последовательных снимка Canvas
не имели различий в пикселях (различия полных страниц были только в карточках выше).
Ошибок консоли нет. JavaScript обоих модулей прошёл синтаксическую проверку.
Итоговый кадр — `animated-effects-review.jpg`.

## Интеграция в игру

Утверждённые корпуса из `assets/*-airframe.png` скопированы в `public/art/approved/`. В `src/aircraft.ts` настроены обрезка прозрачных полей, постепенное уменьшение и центры отдельных вращающихся винтов. `src/scene.ts` использует эти текстуры в бою и анимированных портретах ангара; золотой след рисуется позади премиального самолёта.

Ранее `game-check.html` запускал настоящий `SkyScene` без изменения профилей; теперь его заменила единая страница `/models.html`. Проверены все пять моделей, разворот и пауза: два кадра на паузе идентичны, после продолжения кадры меняются. Кампания также проверена с обычным гостевым профилем. Скриншоты: `in-game-hangar.jpg`, `in-game-flight.jpg`, `in-game-models.jpg`.

Проверки интеграции: production-сборка, 36 тестов, `git diff --check`. У старых моделей сохранены IDs `bastion` и `skate`, чтобы не терять приобретённые самолёты и улучшения. Новая модель `yantar` требует ранга 4 и 1200 серебра.
